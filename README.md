Advanced Network Monitoring and Visualization Tool
--------------------------------------------------
The Advanced Network Monitoring and Visualization Tool is a project under active development by Prranith Swargam.
It is designed to enhance Windows Server security by providing real-time network monitoring, traffic analysis, and visualization.
The tool helps administrators and security teams:
  Monitor network flows between source and destination IPs across all 7 OSI Layers
  Analyze traffic statistics and patterns
  Detect potential anomalies and security threats
  Gain insights into network usage with clear visualizations

✨ Features (Current & Upcoming)
  Real-time packet capture and monitoring
  Flow analysis between source and destination IPs
  Basic traffic statistics (packets, bandwidth, protocols)
  Integration with Windows Server for enhanced security logging
  (In Progress) Advanced visualization dashboard
  (In Progress) Security alerts for suspicious traffic

🛠️ Tech Stack
Language: C++ (with support for Windows APIs,Npcap,WFP)
Libraries: Npcap/WinPcap (for packet capture), Graphing/Visualization frameworks (in progress)
